가상 AD 디렉터리

실제 Active Directory 가 아닌 가상 디렉터리입니다. 작업을 실행하면 이 디렉터리만 바뀌고, 실제 환경용 PowerShell 스크립트는 미실행 상태로 만들어집니다.

계정 생성 (New-ADUser)

계정명 규칙: 영문 이름 머리글자 + 성 (홍길동 → gdhong). 이미 있으면 숫자를 붙입니다 (gdhong2). 초기 비밀번호는 스크립트에 넣지 않습니다.
